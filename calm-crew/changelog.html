What's new in Calm Crew

Every version for testers, newest first. Download the APK from the download folder; the file name has the version in it (calmcrew_<version>.apk). Each version lists its SHA-256 checksum, so you can check that your download is the real file.

0.3.0 (October 4, 2026)

Download: calmcrew_0.3.0.apk from the Google Drive folder · SHA-256 3baa4e966bd5a038158efe50c5cf6da2292ca6acc5026b992d695ea04360d660

The first test version

  • A sunny valley: the home screen is a valley where each activity is a place to visit.
  • Five activities: Counting Garden, Word Treehouse (spelling), Tocky's Echo Shop (speech), Mochi's Cozy Cave (breathing, bubble popping and rain) and My Day (a picture schedule with a countdown).
  • Character voices: Pip, Mochi and Tocky each speak in their own voice, so the app can be used without reading. All 121 spoken lines ship with the app.
  • Pip's garden: every finished activity grows a flower.

For grown-ups

  • Settings open only when you hold the gear button for 3 seconds.
  • Calm mode softens the colors and turns off movement, except the slow breathing bubble.

Calm Crew works fully offline, asks only for vibration, and collects no data.
