What's new in SyntaxDeck

Every version for testers, newest first. Download the APK from the download folder; the file name has the version in it (syntaxdeck_<version>.apk). Each version lists its SHA-256 checksum, so you can check that your download is the real file.

0.1.0 (October 5, 2026)

Download: syntaxdeck_0.1.0.apk from the Google Drive folder · SHA-256 e3ff3c23d58ac0b73261557893fb52ca1c9f6770541e8e8b0ce5dd422846979f

The first test version

  • Linux essentials: 147 commands for files, text, permissions, processes, networking, archives, packages and services.
  • Bash: 46 cards on the shell: pipes and redirects, && and ||, history, aliases, environment variables, and script basics like if, for and functions.
  • Every example was run on Linux (Ubuntu), and its output is shown as it really appears. Commands that delete or overwrite things carry a warning.

In the app

  • Search with results as you type, typo fixes, and symbol searches like 2>&1, >> or $?.
  • Browse each pack, open a card for its syntax, examples, output and common flags, and copy or share it.
  • Saved: star your favorite cards and see the ones you opened recently.
  • Settings: light, dark or system theme, and the size of code text.

SyntaxDeck works fully offline, asks for no permissions and collects no data.
